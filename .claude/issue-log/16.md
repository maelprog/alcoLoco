## Dette héritée de #5 — constats du vérificateur de la PR #48

### MOYEN-1 — un trou de couverture réel, à fermer par un test **actif**

`crates/domain/src/lib.rs:250`, branche « plateau » de `absorbed_alcohol_grams` :

```rust
alcohol_grams * shortest / (2.0 * longest) + alcohol_grams * (tau - shortest) / longest
```

Cette ligne n'est couverte que par un test **`#[ignore]`** — donc **jamais par la CI**. Sonde de
mutation du vérificateur : remplacer `shortest / (2.0 * longest)` par `shortest / longest` laisse
la suite active **entièrement verte** (`25 passed; 0 failed`). Seul le test ignoré
`the_trapezoid_climbs_through_known_values_before_its_peak` la voit, avec **+127 % d'erreur**
(`0,20704764817394483` au lieu de `0,09139014340530568`).

Reproduction :

```bash
sed -i 's|alcohol_grams \* shortest / (2.0 \* longest)|alcohol_grams * shortest / longest|' crates/domain/src/lib.rs
cargo test -p domain              # vert  ← le trou
cargo test -p domain -- --ignored # 3 passed; 1 failed
```

Cause : les tests actifs n'appellent la primitive qu'en `τ ≥ a+b`, sur la branche descendante, ou
sur des dégénérescences où `shortest = 0` / plateau vide.

**Pourquoi c'est à corriger et non à laisser** : l'aire sous `R` et sa primitive sont des
propriétés de §6.4 **indépendantes de l'arbitrage #37**. Elles n'avaient pas à être emportées par
l'`#[ignore]`. **Action** : ajouter un test **actif** sur `absorbed_alcohol_grams(A, 1/3, 1/2, τ)`
pour `m < τ < M`, appelé **directement**, sans passer par la concentration.

remplacer par une assertion sur la valeur exacte.

### MINEUR-6 — angle mort déclaré, à combler

La PR #48 annonce trois garde-fous autour de l'arbitrage #37 ; **deux existent** (#37 est `OPEN`
sur le milestone V1 ; les 4 lignes `ignored, modèle d'absorption non arbitré — cf. #37` sont bien

`AbsorptionProfile` — n'existe pas** : `grep -rn AbsorptionProfile --include=*.rs` ne rend rien,
puisque le trait lui-même appartient à #16. **Quand tu poses `AbsorptionProfile`, pose le
doc-comment avec.**
